[시나리오 03] 클래스 필드 동적 읽기/쓰기 + 메서드 + This 복합 시나리오
========================================================================

참고 요구사항
  - 3일차 PDF: class 관련 요구사항 - 클래스 선언, 인스턴스 생성(Robot()),
    필드 동적 쓰기/읽기/갱신(r.speed = 10; r.speed = r.speed + 5;),
    메서드 선언/호출, This로 필드 접근

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario03_class_field_method.txt

검증 목적
  1) Class Robot { }으로 클래스를 선언하고 Robot()으로 인스턴스를 생성할 수
     있는지 확인한다 (생성자 init 없이도 동작해야 함).
  2) 인스턴스에 존재하지 않던 필드(position/name/speed)에 대입하면 새로
     생성되고, 이후 같은 필드를 읽거나 값을 갱신할 수 있는지 확인한다.
  3) 메서드(move/report) 내부에서 This.position으로 자기 인스턴스의 필드를
     읽고 쓸 수 있는지, 메서드를 여러 번 호출했을 때 상태가 누적되는지
     확인한다.

예상 표준출력 (순서대로)
  [모드: RUN]
  8
  SpeedRobot
  15

각 줄 설명
  - 8  : move(5) -> position 0+5=5, move(3) -> position 5+3=8, report()가 8 출력
  - SpeedRobot : r.name 필드를 그대로 읽음
  - 15 : r.speed(10)에 5를 더해 갱신한 뒤 다시 읽은 값

성공 판정 기준
  - 종료 코드 0
  - 위 3개 줄이 순서대로 정확히 출력됨
