[시나리오 02] 함수 인자 개수 불일치 런타임 오류 시나리오
========================================================

참고 요구사항
  - 3일차 PDF: function 관련 오류 검사 - "인자 개수 불일치"
    (Func foo(a, b, c) { ... } Foo(1, 2); 처럼 파라미터 수와 인자 수가 다른 경우)

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario02_function_error_arity.txt

검증 목적
  - add는 파라미터 2개(a, b)로 선언되었는데 호출 시 인자를 1개(add(1))만
    전달했다. 이 검사는 Checker가 아니라 Executor의 런타임 오류로 처리되는
    설계이므로(Architecture.md §3.2), "print "start";" 까지는 정상 출력된 뒤
    함수 호출 시점에서 실행이 중단되어야 한다.
  - 오류 발생 이후의 "var result = ..." 와 "print result;" 는 절대 실행되지
    않아야 한다(파일 전체가 한 번의 파이프라인으로 실행되며, 예외 발생 시
    즉시 중단하는 FileRunMode 동작을 확인).

예상 표준출력
  [모드: RUN]
  start
  '{함수이름}' 호출에는 인자 {개수}개가 필요합니다 (전달된 인자: {개수}개)

  (정확한 문구는 Executor.cpp의 ExecutorError 포맷 문자열에 따라
   "'add' 호출에는 인자 2개가 필요합니다 (전달된 인자: 1개)" 형태로 출력된다.
   문구 자체보다 "start까지만 출력되고 그 다음 줄이 오류 메시지이며,
   result 관련 출력은 전혀 없다"는 동작을 검증하는 것이 핵심이다.)

성공 판정 기준
  - 종료 코드 1 (비정상 종료)
  - "start"는 출력되지만 "result" 값이 출력되지 않음
  - 오류 메시지에 인자 개수 관련 문구가 포함됨
