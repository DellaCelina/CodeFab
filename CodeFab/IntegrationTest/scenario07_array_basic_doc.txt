[시나리오 07] 정적 배열 생성/순회/변수 인덱스 갱신 복합 시나리오
==================================================================

참고 요구사항
  - 3일차 PDF: 정적 배열 - Array(n)으로 고정 크기 배열 생성, 인덱스를 통한
    읽기/쓰기(arr[i] = v), 변수를 이용한 인덱스 연산(arr[i - 1] = 7)

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario07_array_basic.txt

검증 목적
  1) Array(5)로 크기 5의 배열을 만들고, for 반복문으로 각 인덱스에 값을
     채워 넣을 수 있는지 확인한다.
  2) 리터럴이 아닌 변수 기반 인덱스 연산(idx - 1)으로 배열 원소를 갱신할
     수 있는지 확인한다.
  3) 배열 원소를 다시 반복문으로 순회하며 합계를 구할 수 있는지 확인한다
     (배열이 값 목록으로서 온전히 유지되는지 검증).

예상 표준출력 (순서대로)
  [모드: RUN]
  10
  50
  999
  1129

각 줄 설명
  - 10   : arr[0] = (0+1)*10
  - 50   : arr[4] = (4+1)*10
  - 999  : arr[idx-1] = arr[1]을 999로 덮어쓴 뒤 다시 읽은 값
  - 1129 : arr = [10, 999, 30, 40, 50]의 합계 (10+999+30+40+50)

성공 판정 기준
  - 종료 코드 0
  - 위 4개 줄이 순서대로 정확히 출력됨
