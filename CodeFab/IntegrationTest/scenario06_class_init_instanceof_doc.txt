[시나리오 06] 생성자(init) 인자 전달 + 인스턴스 독립성 + instanceof 복합 시나리오
===================================================================================

참고 요구사항
  - 3일차 PDF: 생성자 - init(name, speed) { This.name = name; This.speed = speed; }
    형태로 인자를 받아 필드를 초기화하고, var r = Robot("AndOr", 10); 처럼
    생성 시 인자를 전달할 수 있어야 한다.
  - 3일차 PDF: 타입 검사 연산자 - instanceof는 자기 자신의 클래스뿐 아니라
    부모 클래스에 대해서도 true를 반환해야 하며, 관계가 없으면 false,
    인스턴스가 아닌 값(숫자 등)에 대해서도 false를 반환해야 한다.

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario06_class_init_instanceof.txt

검증 목적
  1) 같은 클래스(Robot)로 만든 두 인스턴스(r1, r2)가 서로 독립된 필드
     저장소를 갖는지 확인한다 (r1.name이 r2.name에 영향을 주지 않음).
  2) SpeedRobot의 init이 Super.init(name, 999)로 부모 생성자를 호출해
     인자를 전달할 수 있는지 확인한다.
  3) instanceof가 자기 클래스/부모 클래스/관계 없는 클래스/비인스턴스 값에
     대해 각각 올바른 boolean을 반환하는지 확인한다.

예상 표준출력 (순서대로)
  [모드: RUN]
  AndOr
  10
  Zeta
  Sam
  999
  true
  true
  false
  false
  false

각 줄 설명
  - AndOr / 10 : r1의 필드 (r2와 독립적으로 유지됨)
  - Zeta       : r2.name (r1과 섞이지 않음)
  - Sam / 999  : w = SpeedRobot("Sam") -> Super.init("Sam", 999) 결과
  - true       : w instanceof SpeedRobot (자기 자신)
  - true       : w instanceof Robot (부모 클래스도 성립)
  - false      : r1 instanceof SpeedRobot (부모 인스턴스는 자식이 아님)
  - false      : r1 instanceof Cat (관계 없는 클래스)
  - false      : 1 instanceof Robot (인스턴스가 아닌 값)

성공 판정 기준
  - 종료 코드 0
  - 위 10개 줄이 순서대로 정확히 출력됨
