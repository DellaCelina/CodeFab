[시나리오 01] 블록 스코프 + 함수 재귀호출 복합 시나리오
========================================================

참고 요구사항
  - 1일차 PDF: 변수 저장소(Global/Local)와 블록 스코프 생성/소멸, for 반복문
  - 3일차 PDF: function 관련 요구사항 - 함수 선언(Func), return 처리, 재귀 호출

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario01_function_scope.txt

검증 목적
  1) 중첩된 블록에서 같은 이름(a)의 변수가 셰도잉되고, 안쪽 블록에서는 가장
     가까운 스코프의 값을 읽으며, 전역 변수(ga)는 여러 단계를 거슬러 올라가도
     정상적으로 조회되는지 확인한다.
  2) Func로 선언한 함수가 자기 자신을 재귀적으로 호출(fact)할 수 있는지,
     그리고 return 값이 호출식의 평가 결과로 정확히 전달되는지 확인한다.
  3) for문 초기화절에 이미 선언된 변수(i)를 재사용하는 일반 대입 문법이
     정상적으로 파싱/실행되는지 확인한다.

예상 표준출력 (순서대로)
  [모드: RUN]
  7
  100
  7
  120
  10

각 줄 설명
  - 7   : 가장 안쪽 블록에서 print a; -> 가장 가까운 스코프(값 7)를 찾음
  - 100 : 같은 블록에서 print ga;    -> 로컬에 없으므로 전역까지 올라가 100을 찾음
  - 7   : 바깥 블록으로 나온 뒤 print a; -> 여전히 그 블록에서 선언한 a(7)를 읽음
  - 120 : fact(5) = 5*4*3*2*1 = 120 (재귀 호출 결과)
  - 10  : for(i=0;i<5;i=i+1) 동안 sum = 0+1+2+3+4 = 10

성공 판정 기준
  - 종료 코드 0 (실행 중 오류 없이 정상 종료)
  - 위 5개 줄이 순서대로 정확히 출력됨
