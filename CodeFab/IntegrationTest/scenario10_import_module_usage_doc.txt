[시나리오 10] Import 모듈 사용 + alias를 통한 함수/변수 접근 복합 시나리오
===========================================================================

참고 요구사항
  - 3일차 PDF / Architecture.md §7: import "path" alias name; 문법으로 다른
    파일의 최상위 선언(함수/변수)을 가져와 alias.멤버 형태로 접근

준비물
  - scenario10_import_module_usage.txt (실행할 메인 스크립트)
  - scenario10_import_module_lib.txt   (import 대상이 되는 라이브러리 파일,
    add/mul 함수와 version 변수를 선언만 하고 있음)
  - 두 파일은 반드시 같은 폴더(레포 루트)에 있어야 하며, import 경로가
    상대경로이므로 CodeFab.exe를 레포 루트에서 실행해야 정상적으로
    라이브러리 파일을 찾을 수 있다.

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario10_import_module_usage.txt

검증 목적
  1) import 문으로 다른 파일을 읽어 재귀적으로 컴파일하고, alias로 지정한
     이름(mathlib)을 통해 그 파일의 함수(add/mul)와 전역 변수(version)에
     모두 접근할 수 있는지 확인한다.
  2) mathlib.add(...)처럼 모듈 멤버가 함수 호출로도, mathlib.version처럼
     값 읽기로도 문제없이 동작하는지 확인한다.
  3) 사용자가 정의한 함수(useModule) 내부에서도 import한 모듈(mathlib)을
     참조해 호출할 수 있는지 확인한다.

예상 표준출력 (순서대로)
  [모드: RUN]
  7
  12
  1
  11

각 줄 설명
  - 7  : mathlib.add(3, 4)
  - 12 : mathlib.mul(3, 4)
  - 1  : mathlib.version (라이브러리 파일에서 선언한 전역 변수)
  - 11 : useModule(10) -> mathlib.add(10, mathlib.version) = add(10, 1)

성공 판정 기준
  - 종료 코드 0
  - 위 4개 줄이 순서대로 정확히 출력됨
  - 라이브러리 파일이 없거나 경로가 다르면 "import 대상 파일을 열 수
    없습니다" 오류로 실패하므로, 두 파일을 함께 같은 폴더에 두었는지
    먼저 확인한다.
