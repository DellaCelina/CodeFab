[시나리오 08] 배열 인덱스 범위 초과 런타임 오류 시나리오
==========================================================

참고 요구사항
  - 3일차 PDF: 정적 배열 관련 런타임 오류 - "범위를 벗어난 인덱스 접근"
    (var arr = Array(3); print arr[5]; -> 인덱스 범위 벗어남)

실행 방법 (Release 빌드, repo 루트에서 실행)
  CodeFab\x64\Release\CodeFab.exe run scenario08_array_index_error.txt

검증 목적
  - Array(3)으로 만든 배열의 유효 인덱스는 0~2인데, arr[3]으로 범위를
    벗어난 인덱스에 접근했을 때 Executor.cpp::resolveArrayIndex의
    "배열 인덱스 범위를 벗어났습니다." 오류가 발생해야 한다.
  - 배열을 채우는 문장들과 "filled" 출력까지는 정상 진행되고, 범위를
    벗어난 접근 시점에서만 실행이 즉시 중단되어야 한다.

예상 표준출력
  [모드: RUN]
  filled
  배열 인덱스 범위를 벗어났습니다.

  ("unreachable"은 절대 출력되지 않아야 한다.)

성공 판정 기준
  - 종료 코드 1
  - "filled"는 출력되지만 "unreachable"은 출력되지 않음
  - 오류 메시지에 "인덱스"와 "범위" 관련 문구가 포함됨
